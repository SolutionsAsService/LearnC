How this site is built

One Python script, _src/build.py, compiles every program under examples/, runs it, and writes the pages from the results. Change an example, rebuild, and its page changes.

What changed from the old repo

  • The nine original C examples became twelve lessons. Each was compiled with -Wpedantic -Wstrict-prototypes -Wconversion and fixed until it built without warnings.
  • read_file.c stored fgetc's result in a char. That loops forever where char is unsigned and stops early on byte 0xFF where it is signed. Lesson 09 explains the bug.
  • C++, Objective-C, C# and HolyC were added, along with the Rosetta and Family pages.

Design

The text sits on an 80-column grid, the width of a terminal. The home page draws the site as a C pointer diagram: struct boxes, parent pointers and arrays. The design decisions and the critique rounds are in DESIGN-LOG.md in the repository.
