The family

  • C1972

    The root. Memory is yours to manage.

    #include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
  • C++1985

    C with classes, templates and destructors.

    #include <iostream>

int main() {
    std::cout << "Hello, World!\n";
}
  • Objective-C1984

    C plus Smalltalk-style messages.

    #include <stdio.h>

int main(void) {
    printf("Hello, World!\n");   /* Objective-C is a strict superset of C */
    return 0;
}
  • C#2000

    C syntax on a managed runtime.

    using System;

class Program {
    static void Main() {
        Console.WriteLine("Hello, World!");
    }
}
  • HolyC2003–13

    C as the shell of a whole operating system.

    // A string literal on its own is printed. No main, no #include.
"Hello, World!\n";
