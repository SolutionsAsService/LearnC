Objective-C

A struct is one record with named fields. The red wire is its parent pointer: Objective-C grew from C.

Brad Cox and Tom Love added Smalltalk’s message passing to C in the early 1980s. NeXT licensed it in 1988, and through NeXTSTEP it became the language of Mac OS X and iOS until Swift arrived in 2014. Every C program is a valid Objective-C program.

What it adds to C

  • Messages [object message:arg] is looked up at run time, not bound at compile time.
  • nil is safe to message Sending a message to nil returns zero instead of crashing.
  • Categories Add methods to a class you did not write, without subclassing it.
  • Introspection Ask an object at run time whether it responds to a selector.
