C#

Anders Hejlsberg's team at Microsoft announced C# in 2000, and version 1.0 shipped with .NET in 2002. It has C's braces and operators but runs on a managed runtime: a garbage collector frees memory, and indexes are checked.

These examples were compiled with Mono's mcs, which implements C# up to about version 7, so they avoid newer syntax such as records and top-level statements. Modern .NET runs them unchanged.

What it adds to C

  • Garbage collection Objects are freed when nothing refers to them. There is no free and no delete.
  • Value and reference types struct copies like C; class copies the reference.
  • Properties and exceptions Fields guarded by code, and errors that cannot be silently ignored.
  • LINQ Queries over any collection: Where, OrderBy, Select.
