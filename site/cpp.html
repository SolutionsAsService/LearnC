C++

Bjarne Stroustrup began “C with Classes” at Bell Labs in 1979. It was renamed C++ in 1983 and released commercially in 1985. It keeps almost all of C and adds what C leaves to you: types that clean up after themselves, generic code, and a large standard library.

What it adds to C

  • Destructors and RAII A resource is released when the object that owns it goes out of scope. There is no free to forget.
  • References int &a is another name for an existing variable. It is never null and never reseated.
  • Templates One definition, compiled separately for every type it is used with.
  • Classes and virtual functions Inheritance, and calls dispatched at run time through a table of pointers.
  • The standard library vector, string, map and the algorithms that work on them.
