HolyC

Terry A. Davis (1969–2018) wrote HolyC for his own operating system, which he developed alone from 2003 and named TempleOS in 2013. HolyC is both the system's programming language and its shell: you type HolyC at the prompt and it is compiled just in time and run.

Not run here. HolyC is compiled by TempleOS itself, and no HolyC compiler was available in the build environment, so the HolyC programs on this site are shown as source only, with no output. You can run HolyC in your browser at holyc.shadw.app, or inside TempleOS in a virtual machine.

What it adds to C

  • No main Statements at the top level of a file run when the file is included.
  • A string is a print A string literal on its own is printed. Follow it with arguments and it is formatted.
  • Default arguments Any parameter can have a default, and you can skip it in the middle: Greet(, 3).
  • Calls without parentheses A call with no arguments can drop the ().
  • Explicit types I64, U8, F64 and U0 (void) say their size in their name.
