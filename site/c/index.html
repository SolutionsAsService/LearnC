struct lang C · 1972 · Dennis Ritchie, Bell Labs

C

Dennis Ritchie gave types to Ken Thompson's B so that Unix could be written in something higher than assembly. Fifty years later C still runs the kernels, the interpreters and the firmware everything else stands on. It hands you memory and trusts you with it.

What C gives you

  • Direct access to memory through pointers
  • Predictable cost: what you write is close to what runs
  • A tiny language and a compiler on every platform

What C leaves to you

  • Freeing every byte you allocate
  • Staying inside array bounds
  • Strings, error handling, and almost everything else
