Arrays

A row of same-type values in one block of memory, and how to count them.

sizeof numbers / sizeof numbers[0] computes the element count at compile time, but only where the array is still an array. Once it is passed to a function it decays to a pointer and the trick fails.

C does not check indexes. numbers[5] compiles, then reads whatever happens to follow the array.
