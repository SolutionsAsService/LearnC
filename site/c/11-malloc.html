The heap

Ask for memory at run time, and give it back.

malloc returns memory that lives until you free it, or NULL if there is none. Writing sizeof *squares rather than sizeof(int) keeps the size right if the type ever changes. Setting the pointer to NULL after free turns an accidental later use into a clean crash instead of silent corruption.
