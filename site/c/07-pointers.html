Pointers

A variable that holds an address, and the swap that needs one.

&num is the address of num, and *ptr is the value stored there. Writing through *ptr changes num itself. C passes every argument by value, so swap can only reach the caller’s variables when it is given their addresses.

An earlier version of this lesson printed raw addresses with %p. Those change on every run (address space layout randomisation), and passing an int * to %p without a (void *) cast is a warning under -Wpedantic. This version compares the pointers instead.
