Hello, World

The smallest whole program: one include, one function, one call.

#include <stdio.h> pastes in the declarations (the names and argument types) of the standard input/output library, which is where printf lives. Every C program starts running at main. Its int return value goes back to the shell, the program you typed the command into: 0 means success.

Under every program on this site, the dark box shows what it printed. Its header gives the exit code (exit 0 is success) and the number of compiler warnings.

Write main(void), not main(). Before C23 (the 2024 C standard), empty parentheses declared a function whose parameters were unspecified, not absent.
