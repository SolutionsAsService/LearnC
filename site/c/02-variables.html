Variables and types

Each variable has a type, and each type has a size in bytes.

A bit is a single 0 or 1; a byte is 8 bits, enough for a number from 0 to 255. In printf, each % code prints the next argument: %d an int, %c a character, %.2f a double with two decimals, and %zu a size such as sizeof gives.

A char is one byte holding a character code: 'A' is 65. sizeof tells you how many bytes a type or variable takes on this machine. The C standard sets minimums, not exact sizes.

float and double hold numbers with a fractional part; double has twice the precision. An earlier version of this lesson stored 5.9 in a float, which actually holds 5.900000095…, and %.2f (print with two decimals) hid the difference. Use double unless you have a reason not to.
