BCPL → B → C → …

The family

C did not start with C. It grew out of BCPL and B, and its braces, semicolons and for (;;) were copied by languages that share none of its machinery.

  • 1967BCPL Martin Richards, Cambridge. Typeless: everything is a machine word.
  • 1969B Ken Thompson, Bell Labs. BCPL cut down to fit a PDP-7.
  • 1972C Dennis Ritchie adds types to B. In 1973 Unix is rewritten in it.
  • 1978K&R C The C Programming Language by Kernighan and Ritchie becomes the de facto standard.
  • 1984Objective-C Cox and Love add Smalltalk messages to C.
  • 1985C++ Stroustrup’s C with Classes ships commercially.
  • 1989C89 ANSI X3.159-1989; adopted by ISO as C90 in 1990.
  • 1995Java Sun. Borrows C’s syntax for a virtual machine.
  • 1999C99 // comments, <stdint.h>, declarations anywhere.
  • 2000C# Microsoft. C syntax on the .NET runtime.
  • 2001D Walter Bright. A redesign of C++.
  • 2003HolyC Terry A. Davis starts the OS that becomes TempleOS.
  • 2009Go Google; Ken Thompson is one of its three designers.
  • 2011C11 Threads, atomics and _Generic.
  • 2016Zig Andrew Kelley. Aims to replace C, and can compile C.
  • 2018C17 A bug-fix revision of C11.
  • 2024C23 ISO/IEC 9899:2024: bool, nullptr and constexpr keywords, and () now means (void).

The four lanes: the ancestors, the C standard itself, the languages built directly on C (the ones this site teaches), and languages that borrowed C’s syntax without being built on it.
